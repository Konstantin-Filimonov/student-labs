В каждой лабораторной код лежит в `src/`, результаты — в `results/`, инструкция запуска и выводы — в `README.md` этой работы.

## Как запустить

Нужен локальный сервер LM Studio (`http://localhost:1234/v1`) с загруженной моделью. Дальше — в README конкретной лабораторной: зависимости, `.env.example`, команды запуска.

## Секреты

Файлы `.env` в Git не входят. В репозитории только `.env.example` без реальных ключей. Для LM Studio поле `LLM_API_KEY` достаточно заполнить строкой `lm-studio`.
